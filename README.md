## 🚀 Featured Projects

### 🔍 [Visual Knowledge Graph RAG Assistant](https://github.com/krishnareddyalavala)
Multimodal AI system that converts images/documents into structured knowledge graphs using OCR and entity-relationship extraction. Enables graph-based retrieval and contextual Q&A with LLMs + Neo4j for more accurate, explainable responses.

`Python` `Neo4j` `LangChain` `OCR (Tesseract)` `OpenAI` `FastAPI` `Streamlit`

---

### 🤖 [Resume Match Checker — Agentic AI](https://github.com/krishnareddyalavala)
Agentic AI system that evaluates resumes against job descriptions using multi-agent workflows (parsing, skill extraction, semantic matching, scoring). Delivers ATS-style match %, gap analysis, and actionable recommendations.

`LangChain` `LangGraph` `FAISS` `OpenAI` `spaCy` `FastAPI` `Streamlit`

---

### 🏥 [Hybrid RAG for Healthcare Guidelines](https://github.com/krishnareddyalavala)
Hybrid Retrieval-Augmented Generation (RAG) system combining BM25 keyword search and dense semantic retrieval to surface relevant clinical guidelines. Reranking + domain-specific medical context reduces hallucinations for reliable decision support.

`LangChain` `FAISS` `BM25` `Azure OpenAI` `Hugging Face` `FastAPI` `Streamlit`
